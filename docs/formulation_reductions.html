The FED-HPC space-time formulation and its exact reductions

The scheduling problem, the flow model in src/fedhpc/formulations.py, and a proof of each of the six model reductions: N1 normal patterns, N2 compressed graph, R1 collapse, R2 Pareto filter, R3 weighted deadlines and LX lex deadlines. Every exactness proof uses the same two tools: coverings of the feasible set, and the remove-then-left-shift lemma. The LaTeX source of the same text is docs/formulation_reductions.tex.

1The problem

Data

  • Jobs \(\J\). Job \(j\) has arrival \(a_j\in\R\), execution time \(e_j\gt 0\), I/O volume \(\iota_j\ge 0\), demands \((q^{\mathrm{cpu}}_j,q^{\mathrm{mem}}_j,q^{\mathrm{stor}}_j)\) and weight \(w_j\in\R\) (default 1).
  • Instance types \(\M\). Type \(m\) has performance \(P_m\), I/O time \(\tau^{\mathrm{IO}}_m\), deploy time \(\pi_m\), prices \(\kappa^{\mathrm{IO}}_m,\kappa^{\mathrm{VM}}_m,\kappa^{\mathrm S}_m\), sizes \(C^{\cdot}_m\), capacity \(N_m\in\N\cup\{\infty\}\) (capacity=None is \(\infty\)) and fixed usage cost \(U_m\) (fixed_cost).
  • Horizon \(H\ge 1\). A slot \(u\in\{0,\dots,H-1\}\) is \([u,u+1)\); a time or node \(v\in\{0,\dots,H\}\) is an instant.
  • Running jobs: \(\rho\) occupies one unit of a finite-capacity type from 0 until \(e_\rho\ge 1\).

Derived parameters (Instance.build)

\[ \begin{aligned} F_j &= \{m : q^{\mathrm{cpu}}_j\le C^{\mathrm{cpu}}_m,\ q^{\mathrm{mem}}_j\le C^{\mathrm{mem}}_m,\ q^{\mathrm{stor}}_j\le C^{\mathrm{stor}}_m\} &&\text{(eq. 1)}\\ p^{\mathrm{bill}}_{jm} &= e_j/P_m+\tau^{\mathrm{IO}}_m\iota_j &&\text{(eq. 2)}\\ p_{jm} := p^{\mathrm{occ}}_{jm} &= \max\bigl(1,\lceil p^{\mathrm{bill}}_{jm}+\pi_m\rceil\bigr)\in\Z_{\ge 1} &&\text{(eq. 3)}\\ c_{jm} &= \kappa^{\mathrm{IO}}_m\iota_j+\kappa^{\mathrm{VM}}_m p^{\mathrm{bill}}_{jm}+\kappa^{\mathrm S}_m q^{\mathrm{stor}}_j p^{\mathrm{bill}}_{jm} &&\text{(eq. 4)}\\ r_j := \max(0,\lceil a_j\rceil),\quad T_{jm} &= [\,r_j,\ H-p_{jm}\,]_\Z &&\text{(eq. 5)} \end{aligned}\]

The release \(r_j\) is the same on every type. build rejects empty \(F_j\) and empty \(T_{jm}\). Running jobs on unlimited types are discarded. Ends are clipped to \(\min(e_\rho,H)\), and \(R_m\le N_m\) is enforced. For a finite-capacity type:

\[\Run_m(u)=|\{\rho\in\mathcal R_m:e_\rho\gt u\}|,\qquad \Rc_m(v)=|\{\rho\in\mathcal R_m:e_\rho=v\}|.\]

Schedules, feasibility, objectives

Definition 1.1Schedule

A schedule \(\sigma=(\mu,s)\) has \(\mu_j\in F_j\), \(s_j\in T_{j\mu_j}\), and completions \(C_j=s_j+p_{j\mu_j}\). For a type \(m\), with \(\J_m=\{j:\mu_j=m\}\):

\[\Busy_m(u)=|\{j\in\J_m:s_j\le u\lt C_j\}|,\quad \St_m(v)=|\{j\in\J_m:s_j=v\}|,\quad \En_m(v)=|\{j\in\J_m:C_j=v\}|.\]

\(\sigma\) is feasible if \(\Run_m(u)+\Busy_m(u)\le N_m\) for every type and slot. \(\Sched\) denotes the finite set of feasible schedules.

\[f_1(\sigma)=\sum_j w_j(C_j-a_j),\qquad f_2(\sigma)=\sum_j c_{j\mu_j}+\sum_{m\in\mu(\J)}U_m.\]
Assumption 1.2Nonnegative data, nonnegative_data

\(w\ge 0\), \(c\ge 0\), \(U\ge 0\). Then \(f_1\) is nondecreasing in every completion and \(f_2\) does not depend on start times. Also \(C_j-a_j\ge 1\) always, since \(s_j\ge r_j\ge a_j\) and \(p\ge 1\).

The code solves three problem families over \(\Sched\):

  • Weighted sum \(\mathrm W(\alpha,\beta,\varepsilon)\): \(\min\alpha f_1+\beta f_2\) s.t. \(f_1\le\varepsilon\), with \(\alpha,\beta\ge 0\).
  • Lexicographic \(\mathrm L(\varepsilon)\): lex-min \((f_1,f_2)\) s.t. \(f_1\le\varepsilon\).
  • Monotone \(\mathrm M(\Phi,K)\): \(\min\Phi(f_1,f_2)\) s.t. \((f_1,f_2)\in K\), with \(\Phi\) nondecreasing in each argument and \(K\) down-closed. This covers f2 caps (solve_epsilon_cost), box searches and the Pareto front \(\mathrm{ND}(\Sched)\).

2Coverings: the tool behind every exactness proof

Definition 2.1Preorders on schedules
\[\begin{aligned} \sigma'\pP\sigma &\iff f_1'\le f_1\ \wedge\ f_2'\le f_2\\ \sigma'\pW\sigma &\iff f_1'\le f_1\ \wedge\ \alpha f_1'+\beta f_2'\le\alpha f_1+\beta f_2\\ \sigma'\pL\sigma &\iff f_1'\lt f_1\ \vee\ (f_1'=f_1\wedge f_2'\le f_2) \end{aligned}\]

All three are reflexive and transitive. \(\pP\) implies the other two, and each implies \(f_1'\le f_1\). A set \(\hat\Sched\subseteq\Sched\) is a \(\preceq\)-covering if every \(\sigma\in\Sched\) has some \(\hat\sigma\in\hat\Sched\) with \(\hat\sigma\preceq\sigma\).

Lemma 2.2Coverings preserve optimapaper proof here

Let \(\hat\Sched\subseteq\Sched\). (a) A \(\pP\)-covering preserves the optimal value of every monotone problem and the Pareto front: \(\mathrm{ND}(\hat\Sched)=\mathrm{ND}(\Sched)\). (b) A \(\pW\)-covering preserves \(\mathrm W(\alpha,\beta,\varepsilon)\) for all \(\varepsilon\). (c) A \(\pL\)-covering preserves \(\mathrm L(\varepsilon)\) for all \(\varepsilon\). In each case an optimum over \(\hat\Sched\) is an optimum over \(\Sched\).

Proof. \(\Sched\) is finite, so optima exist, and \(\hat\Sched\subseteq\Sched\) can only be worse. Take an optimum \(\sigma^\star\) and its cover \(\hat\sigma\). (a) \(f(\hat\sigma)\le f(\sigma^\star)\in K\), so \(f(\hat\sigma)\in K\) and \(\Phi(f(\hat\sigma))\le\Phi(f(\sigma^\star))\). For fronts: if \(y=f(\sigma)\) is nondominated, its cover has \(f(\hat\sigma)\le y\), hence \(=y\), so \(y\in f(\hat\Sched)\). If \(y\in\mathrm{ND}(\hat\Sched)\) were dominated by some \(f(\sigma')\), then the cover of \(\sigma'\) would dominate \(y\) inside \(f(\hat\Sched)\), a contradiction. (b), (c) The cover keeps \(f_1\le\varepsilon\) and is no worse in the target order. ∎

Coverings compose by transitivity. Every proof below transforms \(\sigma\) through a finite chain of feasible schedules, each \(\preceq\) the one before.

3The space-time model

Single-type bookkeeping

Lemma 3.1Slot recurrencesLean: run_succ, busy_succ, …

For \(0\le u\lt H-1\): \(\Run(u+1)=\Run(u)-\Rc(u+1)\) and \(\Busy(u+1)=\Busy(u)-\En(u+1)+\St(u+1)\). At the boundaries: \(\Rc(0)=0\), \(\Run(0)=R\), \(\En(0)=0\), \(\Busy(0)=\St(0)\); \(\Run(H-1)=\Rc(H)\), \(\Busy(H-1)=\En(H)\), \(\St(H)=0\).

Proof. A job occupies \(u+1\) but not \(u\) iff it starts at \(u+1\), and \(u\) but not \(u+1\) iff it completes at \(u+1\); likewise for running jobs. At 0, \(e_\rho\ge 1\) and \(C_j\ge 1\). At \(H\), everything ends by \(H\), and \(s_j\le H-1\). ∎

With \(\Idle(u):=N-\Run(u)-\Busy(u)\), capacity feasibility is \(\Idle\ge 0\), and

\[\Idle(0)=N-R-\St(0),\qquad \Idle(u+1)=\Idle(u)+\Rc(u+1)+\En(u+1)-\St(u+1).\tag{I}\]

The model

Allowed starts are \(S_{jm}\subseteq T_{jm}\) (equal to \(T_{jm}\) in the plain model), and \(X=\{(j,m,t):m\in F_j,\ t\in S_{jm}\}\). An unlimited type uses \(\bN_m=|\J|\); otherwise \(\bN_m=N_m\).

  • \(x_{jmt}\in\{0,1\}\): job \(j\) starts on \(m\) at \(t\) (eq. 21).
  • \(y_{mt}\ge 0\): idle units of \(m\) in slot \(t\), integer unless continuous_idle (eq. 22).
  • \(z_m\in\{0,1\}\) for each \(m\) with \(U_m\gt 0\).
\[\begin{aligned} &\textstyle\sum_{m,t}x_{jmt}=1 && j\in\J &&\text{(A)}\\ &y_{m,v-1}+\textstyle\sum_{j}x_{j,m,v-p_{jm}}+\Rc_m(v)=y_{m,v}+\textstyle\sum_j x_{jmv} && v\in[0,H]_\Z &&\text{(F)}\\ &\textstyle\sum_{t}x_{jmt}\le z_m && U_m\gt 0 &&\text{(Z)} \end{aligned}\]

The boundary constants are \(y_{m,-1}=\bN_m-R_m\) and \(y_{m,H}=\bN_m\) (eq. 14). The code's \(\max(0,\cdot)\) is inactive because \(R_m\le N_m\). The objectives are \(f_1=\sum w_j(t+p_{jm}-a_j)x_{jmt}\) and \(f_2=\sum c_{jm}x_{jmt}+\sum U_mz_m\). Both iterate over the model's own \(X\), so they stay correct when \(X\) shrinks. \(\Rep(\mathcal M)\) is the set of schedules whose incidence vector extends to a feasible \((x,y,z)\).

Theorem 3.2Flow conservation ⇔ capacitypaper proof here

For a fixed schedule, the rows (F) of type \(m\) have exactly one solution, \(y_{m,u}=\Idle_m(u)\). So \(x^\sigma\) extends to \(y\ge 0\) iff \(\sigma\) is capacity-feasible on \(m\), and then \(y\) is integral. In particular, continuous_idle is exact.

Proof. Row 0 gives \(y_0=\bN-R+\Rc(0)-\St(0)=\Idle(0)\). Rows \(1..H-1\) give \(y_v=y_{v-1}+\En(v)+\Rc(v)-\St(v)\), which is \(\Idle(v)\) by (I). Row \(H\) reads \(\Idle(H-1)+\En(H)+\Rc(H)=\bN\); this holds by Lemma 3.1. ∎
Lemma 3.3Fixed costspaper proof here

With \(U\ge 0\), (Z) for binary \(x^\sigma\) reads \(z_m\ge\ind{m\in\mu(\J)}\). The least such \(z\) gives \(f_2(x,z)=f_2(\sigma)\), so every problem nondecreasing in \(f_2\) is solved correctly. The aggregated per-\((j,m)\) row is LP-tighter than \(x_{jmt}\le z_m\). With \(U_m\lt 0\) the plain model would set \(z_m=1\) on unused types.

The occupancy formulation uses \(w_{mt}=\Busy_m(t)\le\max(0,\bN_m-\Run_m(t))\). It represents \(\Sched\) by definition, and no reduction is applied to it.

Proposition 3.4cover_ge (Σx ≥ 1)paper proof here

Under nonnegative data, the optimal values are unchanged: deleting a surplus copy lowers occupancy and changes the objective by \(-\alpha w_j(C-a_j)-\beta c_{jm}\le 0\). In N2, the repair also needs Theorem 6.6. An optimum can still duplicate a job when that copy contributes 0, which happens iff \(\alpha w_j=0\) and \(\beta c_{jm}=0\) (for example \(w_j=0\) on a free on-prem type). The class docstring's claim that no optimum duplicates a job therefore needs \(\alpha w_j\gt 0\).

4Left shifts and normal patterns (one type)

Fix a finite-capacity type and jobs \(J\) on it with starts \(s_j\in[r_j,H-p_j]\). \((J,s)\) is left-shifted if every \(j\) with \(s_j\gt r_j\) has the slot \(s_j-1\) full: \(\Run+\Busy=N\) there.

Theorem 4.1Existence of a left shiftLean: exists_leftShift

Every feasible \((J,s)\) has a feasible left-shifted \(s'\) with \(r_j\le s'_j\le s_j\).

Proof. Induction on \(\sum_j s_j\). If some \(j\) has \(s_j\gt r_j\) and slot \(s_j-1\) not full, start \(j\) one slot earlier. Occupancy rises by 1 only in that non-full slot, so it stays \(\le N\), and the sum drops by 1. ∎
Definition 4.2Pattern set

\(P\subseteq\N\) is a pattern set if (P1) \(r_j\in P\) for every job feasible on the type; (P2) \(e_\rho\in P\) for every running end; (P3) \(q\in P,\ q\ge r_j,\ q+p_j\le H\Rightarrow q+p_j\in P\). The least pattern set is the set of normal patterns \(P^\star\) (Kramer et al. 2020, Alg. 1).

Theorem 4.3Left-shifted starts are patternsLean: leftShifted_mem_pattern

If \((J,s)\) is feasible and left-shifted, then \(s_j\in P\) for every pattern set \(P\).

Proof. Strong induction on \(s_j\). If \(s_j=r_j\), use (P1). Otherwise slot \(v-1\) is full, where \(v=s_j\). Slot \(v\) is within capacity and contains a start, so Lemma 3.1 gives \(\Rc(v)+\En(v)\ge\St(v)\ge 1\). Either a running job ends at \(v\) (P2), or some \(k\) with \(s_k\lt v\) ends at \(v\): \(s_k\in P\) by induction, and \(v=s_k+p_k\in P\) by (P3). ∎
Lemma 4.4The computed mask is a pattern setpaper proof here

normal_pattern_starts and _ext/graph.cpp seed the releases and running ends, then sweep \(q=0..H\) upward. For each distinct \(p\) they mark \(q+p\) when \(q\ge a_{\min}(p)\), the smallest release among jobs with that \(p\). Marks only go to larger indices, so \(q\)'s mark is final when it is visited. Since \(a_{\min}(p_j)\le r_j\), (P3) holds. The result is generally a strict superset of \(P^\star\), which is safe.

Rulenormal_patterns=True

\(S_{jm}:=T_{jm}\cap P_m\). The full time grid of \(y\) and the rows (F) are kept.

Theorem 5.1N1 is a \(\pP\)-covering (needs \(w\ge 0\))composes Lean results
Proof. Soundness is Theorem 3.2. Given \(\sigma\), left-shift each flow type separately (Theorem 4.1). The new starts lie in \(P\) (Theorem 4.3 and Lemma 4.4) and still satisfy \(s'+p\le H\). \(\mu\) is unchanged, so \(f_2\) is unchanged, and \(f_1\) does not rise. ∎

6N2: the compressed arc-flow graph

Rulecompressed_flow=True
  • Events \(E=\{0,H\}\cup\{r_j\}\cup\{e_\rho\}\); nodes \(V=P_m\cup\{0,H\}\supseteq E\).
  • One loss arc per node \(q\lt H\), from \(q\) to \(\Nxt(q)=\min\{e\in E:e\gt q\}\), carrying a continuous flow \(\ell_q\in[0,\bN]\).
  • Job arcs \((t,t+p)\) for \(t\in T\cap P\). Both ends are nodes by (P3).
\[\ind{v=0}(\bN-R)+\ind{v\gt 0}\!\!\sum_{\Nxt(q)=v}\!\!\ell_q+\En(v)+\Rc(v)=\ind{v=H}\bN+\ind{v\lt H}\ell_v+\St(v)\qquad(v\in V)\tag{CF}\]

The grid model is the special case \(E=V=[0,H]\). Let \(\Lambda(u)=\sum_{q\le u\lt\Nxt(q)}\ell_q\) be the idle flow spanning slot \(u\) (arcIdle).

Lemma 6.1Arc bookkeepingLean: arc_succ, inLoss_of_mem_E, …

(a) \(\Lambda(0)=\ell_0\). (b) \(\Lambda(u+1)=\Lambda(u)-\sum_{\Nxt(q)=u+1}\ell_q+\ind{u+1\in V}\ell_{u+1}\). (c) No arc ends at a time \(v\notin E\). (d) For \(v\in E\), \(v\gt 0\): \(\sum_{\Nxt(q)=v}\ell_q=\Lambda(v-1)\), because every arc spanning \(v-1\) must stop at the event \(v\).

Theorem 6.2SoundnessLean: invariant, sound, soundR

If all job arcs lie on nodes and \(\ell\ge 0\) (real) satisfies (CF), then \(\Lambda(u)+\Run(u)+\Busy(u)=\bN\) for every slot. In particular, capacity holds.

Proof. Induction on \(u\). Base: row 0. Step to \(v=u+1\): if \(v\in V\), row \(v\) and Lemma 6.1(b) change \(\Lambda\) by \(\En+\Rc-\St\) at \(v\), exactly offsetting Lemma 3.1. If \(v\notin V\), then \(v\notin E\), and nothing starts, ends or is released at \(v\), so all terms are unchanged. ∎
Lemma 6.3Idle never drops at non-eventsLean: idle_mono

For a feasible left-shifted schedule and \(0\lt v\lt H\) with \(v\notin E\): \(\Idle(v-1)\le\Idle(v)\). If some job starts at \(v\), it is not at its release (\(v\notin E\)), so slot \(v-1\) is full and \(\Idle(v-1)=0\). Otherwise \(\Idle(v)-\Idle(v-1)=\En(v)\ge 0\).

Theorem 6.4Completeness for left-shifted schedulesLean: lossOf, arcIdle_lossOf, complete

For a feasible left-shifted schedule with arcs on nodes, \(\ell_q=\Idle(q)\) for \(q\in E\) and \(\ell_q=\Idle(q)-\Idle(q-1)\) otherwise. This flow satisfies \(0\le\ell\le\bN\), \(\Lambda=\Idle\), and every row (CF).

Proof. Nonnegativity comes from Lemma 6.3. \(\Lambda=\Idle\) by induction: at an event, the arcs into \(v\) carry exactly \(\Lambda(v-1)\) (Lemma 6.1d), which is replaced by \(\ell_v=\Idle(v)\). At a non-event node the increment is added. At a non-node nothing changes. Each row then reduces to (I). ∎
Example 6.5Removal alone is unsound

Take \(N=1\), \(H=10\), and jobs \(A\) (\(p=3\)) and \(B\) (\(p=2\)), both released at 0. Then \(E=\{0,10\}\) and every loss arc jumps to 10. \(A@0,B@3\) has the flow \(\ell_0=\ell_3=0\), \(\ell_5=1\). Now move \(A\) to the cloud. Row 0 forces \(\ell_0=1\), which leaves along \(0\to 10\), and row 3 then needs \(\ell_3=-1\). So \(B@3\) is no longer representable, although it is capacity-feasible. Shifting \(B\) to 0 repairs it.

Theorem 6.6Represent; remove then left-shiftLean: represent, remove_then_leftShift

(a) Every capacity-feasible \((J,s)\) has \(s'\) with \(r_j\le s'_j\le s_j\), \(s'_j\in P\), and a compressed flow. (b) If \((J,s)\) has a compressed flow and \(J'\subseteq J\), the remaining jobs may lose their flow, but after a left shift they have one, with starts in \(P\) and no later than before.

Proof. (a) Theorems 4.1, 4.3 and 6.4, with (P3) placing the arc ends on nodes. (b) Theorem 6.2 gives capacity; removing jobs keeps it; then apply (a). ∎
Theorem 6.7N2 is a \(\pP\)-covering (needs \(w\ge 0\))composes Lean results

Soundness comes from Theorem 6.2 per type, and the covering from Theorem 6.6(a) per type.

7Unbounded types, R1 and R2

From here on nonnegative data is assumed. If it fails, _reduce is skipped.

Definition 7.1Unbounded type, unbounded_types

\(m\in\U\) iff \(N_m=\infty\) or \(N_m-R_m\ge n_m:=|\{j:m\in F_j\}|\). Then \(\Run+\Busy\le R_m+n_m\le N_m\), so every assignment to \(m\) is feasible (Lemma 7.2). \(\Mcap=\M\setminus\U\).

Lemma 7.3Relocationpaper proof here

Moving job \(j\) from a feasible \(\sigma\) to \((k,r_j)\) with \(k\in\U\cap F_j\) gives a feasible \(\sigma'\) with

\[f_1(\sigma')-f_1(\sigma)=w_j(r_j+p_{jk}-C_j),\qquad f_2(\sigma')-f_2(\sigma)\le c_{jk}-c_{j\mu_j}+U_k,\]

and without the \(U_k\) term if \(U_k=0\). The proof uses \(\mu'(\J)\subseteq\mu(\J)\cup\{k\}\) and \(U\ge 0\); the source type only loses occupancy.

Write \(C_{jk}:=\min S_{jk}+p_{jk}=r_j+p_{jk}\) for the earliest completion on \(k\). The release is in \(T\) and is a pattern seed, so \(\min S_{jk}=r_j\) in every configuration.

Rule R1collapse_unbounded

For \(k\in\U\): \(S_{jk}:=\{r_j\}\), and \(k\) gets no flow network.

Lemma 7.4R1paper proof here

Moving every job on an unbounded type to its release is feasible by Lemma 7.2, leaves \(f_2\) unchanged and does not raise \(f_1\): \(\pP\). Without a flow network, only (A) and (Z) mention \(k\).

Rule R2pareto_unbounded

Scan the unbounded options \(K^0_j\) by the key \((C_{jk},c_{jk},\ind{U_k\gt 0},k)\), tracking \(b=\min\{c_{jd}:d\text{ kept},U_d=0\}\). Keep \(k\) iff \(c_{jk}\lt b\). The kept options form \(K^2_j\).

Lemma 7.5R2paper proof here

Each rejected \(k\) has a kept \(d\), scanned earlier, with \(U_d=0\), \(C_{jd}\le C_{jk}\) and \(c_{jd}\le c_{jk}\). Relocating to \(d\) is \(\pP\). The first option scanned is always kept, so \(\min_{K^2}C=\min_{K^0}C\). Options with a fixed cost never act as dominators, because their marginal cost depends on the other jobs.

8R3: rejection deadlines for weighted sums

Hint objective=(α, β) with \(\alpha,\beta\ge 0\). Target problems: \(\mathrm W(\alpha,\beta,\varepsilon)\).

\[\varphi_j(m,t)=\alpha w_j(t+p_{jm}-a_j)+\beta c_{jm}\ \ (\text{nondecreasing in }t),\qquad \rho_{jk}=\varphi_j(k,r_j)+\beta U_k .\]

\(\varphi_j(m,t)\) is the job's own contribution to the scalar objective, and \(\rho_{jk}\) bounds what placing \(j\) on \(k\) adds, fixed cost included.

Rule R3rejection_deadlines

Unbounded options. Scan \(K^2_j\) by \((\rho,C,k)\). Keep \(k\) unless an already-kept \(d\) has \(C_{jd}\le C_{jk}\) and \(\rho_{jd}\le\varphi_j(k,r_j)\). The kept options form \(K^3_j\).

Capacitated types.

\[\tau_{jmk}=\min\{t\ge \min S_{jm}:\varphi_j(m,t)\ge\rho_{jk}\},\quad \theta_{jmk}=\max(C_{jk}-p_{jm},\tau_{jmk}),\quad \Cut_{jm}=\min_{k\in K^3_j}\theta_{jmk},\]

and only starts \(t\lt\Cut_{jm}\) are kept (_first_start_reaching, _truncate).

Lemma 8.1Shape of the deadlinepaper proof here

\(t\) is removed iff some \(k\in K^3_j\) has \(t+p_{jm}\ge C_{jk}\) and \(\varphi_j(m,t)\ge\rho_{jk}\). Both conditions only become true as \(t\) grows, so their union over \(k\) is the up-set \(\{t\ge\Cut_{jm}\}\).

Lemma 8.2R3 movespaper proof here

If \(j\) sits on a removed option \((m_0,t_0)\), there is \(d\in K^3_j\) with \(C_{jd}\le C_j\) and \(\rho_{jd}\le\varphi_j(m_0,t_0)\). No chain is needed, because rejection compares only against kept options. Relocating \(j\) to \(d\) gives

\[\Delta f_1=w_j(C_{jd}-C_j)\le 0,\qquad \alpha\Delta f_1+\beta\Delta f_2\le\rho_{jd}-\varphi_j(m_0,t_0)\le 0,\]

that is, \(\pW\). The source's fixed cost is never credited and the target's is always charged in full, so the rule holds whatever the other jobs do.

Example 8.3Invalid under an f2 cap

One job with \(a_j=0\) and \((\alpha,\beta)=(1,1)\). On-prem it completes at 10 with \(c=0\); on the cloud it completes at 2 with \(c=1\). The on-prem score is \(10\ge\rho=3\), so R3 removes it. Under \(f_2\le\tfrac12\) the reduced model is then infeasible while the full model is not. Callers with an f2 cap must pass objective=None. The same example breaks LX.

9LX: deadlines for the lexicographic objective

Rule LXlex_deadlines, hint LEX_F1

For \(w_j\gt 0\) and \(K^2_j\ne\emptyset\), let \(c^\star_j=\min_{K^2_j}C_{jk}\). Keep only the unbounded options with \(C_{jk}=c^\star_j\), and on capacitated types only the starts with \(t+p_{jm}\le c^\star_j\). Jobs with \(w_j=0\) are exempt.

Lemma 9.1LX movespaper proof here

If \(w_j\gt 0\) and \(C_j\gt c^\star_j\), relocating \(j\) to a fastest kept option lowers \(f_1\) by \(w_j(C_j-c^\star_j)\ge w_j\). Both completions are integers, so the gap is at least 1. The move is strictly \(\pL\).

Proposition 9.2LX keeps every f1-optimumpaper proof here

Every f1-optimal schedule, with or without an f1 cap, meets all LX deadlines. Otherwise Lemma 9.1 would improve it.

Proposition 9.3The δ = 10⁻⁶ of the second phasepaper proof here

The second phase minimises \(f_2\) s.t. \(f_1\le f_1^\star+\delta\). If \(\delta\lt w_{\min}=\min\{w_j:w_j\gt 0\}\), no schedule in that band violates a deadline: one that did would give \(f_1\lt f_1^\star\). So the reduced and full models agree.

10The main theorem

Theorem 10.1Exactness of the reduced modelpaper proof here

Assume nonnegative data. Let \(\mathcal M_h\) be built with hint \(h\), and let \(\preceq_h\) be \(\pP\) for None, \(\pW\) for \((\alpha,\beta)\) and \(\pL\) for LEX_F1. Then \(\Rep(\mathcal M_h)\subseteq\Sched\), and \(\Rep(\mathcal M_h)\) is a \(\preceq_h\)-covering of \(\Sched\). Hence:

  • \(\mathcal M_{\texttt{None}}\) is exact for every monotone problem, including f2 caps and the Pareto front.
  • \(\mathcal M_{(\alpha,\beta)}\) is exact for \(\mathrm W(\alpha,\beta,\varepsilon)\).
  • \(\mathcal M_{\texttt{LEX\_F1}}\) is exact for \(\mathrm L(\varepsilon)\).
Proof. Soundness follows from Theorem 3.2 or 6.2 on flow types, Lemma 7.2 on types without a flow network, and Lemma 3.3. Covering: starting from \(\sigma\in\Sched\),
  1. R1. Move jobs on unbounded types to their releases (\(\pP\)).
  2. R2. Relocate jobs on R2-removed options to their dominators (\(\pP\)).
  3. Hint-specific. Relocate jobs on R3-removed options (\(\pW\)), or LX violators (\(\pL\)). Relocations only remove jobs from capacitated types. The remaining jobs there keep their original starts, which satisfy the deadline.
  4. Representation. In the grid nothing more is needed. For N1/N2, left-shift each capacitated type (Theorem 6.6a). Every deadline is an upper bound on the start, so moving earlier preserves it, and the step is \(\pP\).
Transitivity of \(\preceq_h\) finishes the proof. ∎

Each flag can be turned off independently. Without R1, unbounded types keep their flow network and stage 4 also runs on them. The comparisons use \(C_{jk}=r_j+p_{jk}\), which lower-bounds every completion on \(k\). Stage 4 is necessary because of Example 6.5, and it is also why every deadline in R3 and LX bounds the start from above.

Open points
