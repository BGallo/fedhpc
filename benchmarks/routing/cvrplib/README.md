# Capacitated vehicle routing (CVRPLIB)

Source: <https://galgos.inf.puc-rio.br/cvrplib/en/cvrp>, downloaded
2026-11-26. `X.7z` and `X/` contain the official 100 X-set instance files,
downloaded from <https://galgos.inf.puc-rio.br/cvrplib/en/download/instance-set/17>.
The downloaded archive contains instances, not a complete reference-solution
snapshot. `A/` contains the small `A-n32-k5` instance and its upstream
reference solution (instance and BKS endpoints, ID 4).

Respect each set's route-count and distance-rounding conventions. A best-known
solution is not automatically a proof of optimality. Consult the upstream
catalogue for current bounds and status; do not infer the fleet limit from
an instance name without checking the set's rules.
